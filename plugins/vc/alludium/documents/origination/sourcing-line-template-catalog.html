Sourcing Line Template Catalog

Starter patterns for Fund-specific, repeatable sourcing experiments.

When this source is used as a rendered task output, create the final deliverable as a standalone safe static HTML artifact with a .html filename and mimeType: "text/html". Use the shared VC document styling rules from Template Use Guidance. Do not create Markdown output artifacts from this source.
Use these templates as starting hypotheses, not immutable provider recipes. Every Sourcing Line is a first-class project with its own active Fund, configuration, receipts, candidates, and learning history. No Origination Hub project is required.

Sourcing Line Contract

A line is Fund x registered sources x query or screen x cadence x review policy x outreach policy. Create only line_name and an active canonical fund_id initially. Configure the experiment in its own manager chat. Schedules, paid reads, external writes, candidate creation, and outreach remain disabled until separately reviewed and approved.

Required Instantiation Record

  • line_name, stable Sourcing Line project identity, and active canonical fund_id.
  • starter_template_key and one coherent hypothesis or learning question.
  • Approved source keys, connection assumptions, scope, filters, exclusions, and evidence requirements.
  • Cadence, timezone, cursor/window policy, result limit, budget, review threshold, and owner.
  • Outreach mode, approval owner, do-not-contact rules, success measures, review date, and retirement condition.

Candidate Provenance

Every proposed candidate must preserve the originating Sourcing Line relationship and its source receipts. If another line later finds the same company, add that independent provenance relationship to the existing Candidate rather than choosing an exclusive owner line or duplicating the Candidate.

Fund And Promotion Boundary

The line uses only the active Fund record matching its fund_id. That Fund does not automatically become the Candidate's eventual Deal Fund. Deal promotion requires the user to explicitly select the active target Fund after reviewing all line provenance and candidate evidence.
