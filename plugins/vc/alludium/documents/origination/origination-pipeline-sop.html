Origination Operating SOP

Hub-free operating method for workspace origination, Fund-specific lines, and multi-line candidates.

When this source is used as a rendered task output, create the final deliverable as a standalone safe static HTML artifact with a .html filename and mimeType: "text/html". Use the shared VC document styling rules from Template Use Guidance and make any generated links open in a new tab or window with target="_blank" and rel="noopener noreferrer". Do not create Markdown output artifacts from this source.

Purpose

Use this SOP to operate origination as a workspace projection over the Sourcing Lines and Candidates the current user may access. No singleton Origination Hub project is required. Each line owns one Fund-specific sourcing experiment; each Candidate owns company identity, all line provenance, evidence, decisions, outreach context, and reviewed Deal promotion.

Source Provenance

Every Candidate should preserve source family, source detail, owner, freshness, relationship path, evidence quality, dedupe state, and one native provenance relationship for every contributing Sourcing Line. A later discovery adds evidence; it does not replace earlier line context or create an exclusive primary line. When dedupe finds an exact existing Candidate, stop guided Candidate creation and use the reviewed link-existing-origination-candidate task to add the new line relationship from the platform receipt. Promotion carries that trail into the downstream Deal Pipeline.

Fund Boundary

Each Sourcing Line uses only the active Fund record matching its fund_id. Candidate evidence may span lines associated with different Funds. The eventual Deal Fund is a separate human choice made during promotion and must never be inferred from the first, latest, or majority line.

Workspace Reporting

The Origination Manager derives attention, health, performance, and promotion readiness from current visible line and Candidate projects and their receipts. There is no mandatory cross-line digest schedule or cached hub count. State the reviewed scope and freshness, and link the underlying projects or artifacts.

Controls

Do not create Deals, mutate CRM records, contact founders, incur paid-source spend, or enable recurring schedules without explicit human approval. Connected applications are workspace resources; per-line configuration and evidence determine how they may be used.
