Decision Record

Durable record of one explicitly human-confirmed investment decision.

Create a new standalone safe static HTML artifact using mimeType: text/html for each distinct directly confirmed decision or reapproval. An agent recommendation, inferred outcome, lifecycle state, or memo never authorizes creation.

History and supersession

Approval Rule

The Deal Manager may create this record only after a direct authenticated user message identifies the human-confirmed outcome, rationale and decision authority, and either supplies or explicitly accepts named gaps in conditions, dissent, date, participants and evidence basis. Agent-origin messages never confer approval. Corrections to the same confirmed decision require explicit approval and revision metadata; a distinct reconsideration creates an additional record and never erases history.
